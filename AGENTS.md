# Aturan Otomatis AI Agent & Konvensi Proyek

## 1. Generasi Otomatis Commit Message Git
Setiap kali melakukan pembaruan kode, perbaikan bug, atau penambahan fitur, AI Agent wajib menyertakan **Format Commit Message Git** (Conventional Commits) secara otomatis di akhir setiap respon tanpa perlu diminta oleh pengguna secara manual.

### Format Standar Commit Message:
```text
<type>(<scope>): <deskripsi singkat ringkas>

- Detail perubahan 1
- Detail perubahan 2
```

**Tipe Commit:**
- `feat`: Penambahan fitur baru
- `fix`: Perbaikan bug / error
- `refactor`: Perapihan / restrukturisasi kode
- `style`: Penyesuaian tampilan UI / Tailwind CSS
- `docs`: Pembaruan dokumentasi

## 2. Bahasa & Komunikasi
